# OpenChimeraNFT

**OpenChimeraNFT** — открытая (очищенная) локальная сборка плагина **Chimera NFT** для [exteraGram](https://exteras.org/): NFT-подарки в профиле, коллекционные юзернеймы и номера, рейтинг, верификация, магазин и конструктор подарков.

- **Автор сборки:** [@Coder_Minecraft](https://t.me/Coder_Minecraft)
- **Оригинальный плагин:** Chimera NFT от [@xarmaq](https://t.me/xarmaq)
- **Исходный код:** https://github.com/m4rker20-rgb/OpenChimeraNFT

> ⚠️ Это очищенная версия оригинального Chimera NFT. Вся заслуга за идею и основную функциональность — оригинальному автору @xarmaq. Сборка предназначена для личного использования.

## Чем отличается от оригинала

Из плагина **полностью удалены все обращения к серверу автора** и **вся система банов**. Плагин работает только локально, внутри вашего Telegram-клиента:

| Было (оригинал) | Стало (OpenChimeraNFT) |
|---|---|
| Access-гейт: при каждом старте шлёт на сервер ваш user id, username, **все ID аккаунтов клиента** и client_id | ❌ Проверка запрещена: мгновенный локальный `allowed`, ничего не отправляется |
| Ban-система: шторка бана, самоудаление плагина, репорт всех аккаунтов на сервер, «липкие» маркеры бана на устройстве | ❌ Удалена полностью: обработчики-заглушки, старые ban-маркеры стираются при первом запуске |
| Sync-клиент: **каждые ~12 сек** выгружает на сервер ваши подарки, NFT-username, статусы | ❌ `enabled=False` — SyncClient вообще не создаётся |
| Java-ядро (DEX) со своим HTTP-клиентом: `/api/v1/access`, `/badges`, `/market`, `/transfers` | ❌ Серверные эндпоинты нейтрализованы в DEX, база — `127.0.0.1:9` |
| Автообновление с VPS + канал `eblannftlogs` (автор мог удалённо залить код) | ❌ Удалено: bootstrap отключён, канал нейтрализован. Обновления — только вручную отсюда |

При этом **вся локальная функциональность сохранена**: NFT-подарки в профиле, коллекционные юзернеймы и номера, рейтинг, верификация, каталог/конструктор подарков, хуки профиля, кэш. Запросы самого Telegram (аватары, TL-схемы) не тронуты — это часть мессенджера, а не «сервер плагина».

## Установка

1. Скачайте готовый плагин: [`plugin/OpenChimeraNFT.eaf`](plugin/OpenChimeraNFT.eaf)
2. В exteraGram: **Настройки → Плагины → «+»** → выберите файл (или отправьте файл себе в чат и тапните по нему)
3. Перезапустите Telegram

> Формат `.eaf` — это zip-архив с `refmap.yml` + кодом плагина. Не переименовывайте в `.zip`/`.plugin` — движок требует именно `.eaf`.

Если раньше стоял оригинальный Chimera NFT — при первой загрузке эта сборка сама удалит оставшиеся ban-маркеры (`plugin_access.json*`) на устройстве.

```
│   │   ├── sync_client.py

│   ├── core-smali/                 # Java-ядро в smali (серверные эндпоинты нейтрализованы)

```

## Как устроен плагин

`.eaf` — zip-архив: `refmap.yml` (карта путей), `chimeranft/meta.yml` (метаданные), `chimeranft/src/loader.py` (Python-загрузчик), `chimeranft/java/engine.dex` (Java-ядро), ресурсы и локали.

Загрузчик содержит два блоба в base64:

1. **`engine.dex`** — Java-ядро (`com.chimeranft.core.*`): хуки профиля/подарков, состояние, кэш. Грузится через `InMemoryDexClassLoader`.
2. **`runtime_payload.zip`** — Python-runtime (`chimeranft_runtime/`): карточки настроек, каталог подарков, UI. Распаковывается с проверкой SHA-256.

## Скрытие обычных (неулучшенных) подарков

Скрыть визуальный (неулучшенный) подарок можно **только зажатием карточки подарка в профиле → «Скрыть»** — это работает, начиная с v1.3.19.

> ⚠️ **Ограничение:** кнопка «Скрыть» **внутри самого подарка** (через меню подарка) на неулучшенных подарках выдаёт ошибку `STARGIFT_ALREADY_CONVERTED` — сервер Telegram считает такой подарок уже конвертированным и отклоняет запрос. Используйте зажатие карточки в профиле.
