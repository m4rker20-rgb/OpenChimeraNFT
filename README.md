# OpenChimeraNFT

**OpenChimeraNFT** — открытая (очищенная) локальная сборка плагина **Chimera NFT 1.1.3** для [exteraGram](https://exteras.org/): NFT-подарки в профиле, коллекционные юзернеймы и номера, рейтинг, верификация, магазин и конструктор подарков.

- **Автор сборки:** [@Coder_Minecraft](https://t.me/Coder_Minecraft)
- **Оригинальный плагин:** Chimera NFT 1.1.3 от [@xarmaq](https://t.me/xarmaq)
- **Исходный код:** https://github.com/m4rker20-rgb/OpenChimeraNFT

> ⚠️ Это очищенная версия оригинального Chimera NFT. Вся заслуга за идею и основную функциональность — оригинальному автору @xarmaq. Сборка предназначена для личного использования.

## Чем отличается от оригинала

Плагин работает **полностью офлайн**: все серверные флоу оригинала переведены на локальные заглушки, ничего не отправляется и ничего не блокируется.

| Было (оригинал 1.1.3) | Стало (OpenChimeraNFT 1.1.3) |
|---|---|
| Access-гейт: при каждом старте запрашивает вердикт на сервере (user id, username, device key), при отказе — шторка бана | ✅ Всегда `allowed`: гейт-функции заменены локальными заглушками, deny-презентаторы отключены |
| Ban-система: шторка бана, Java-side `AccessDeniedCallback`, «липкие» маркеры в `plugin_access.json` | ✅ Мертва на всех уровнях: callback-канал отключён, старые deny-кэши игнорируются и не читаются |
| Seed-fetch: запрос server share у `/api/v1/key/<build>` + Telegram-авторизация (identity/session) | ✅ Server share зашит в лоадер, identity-запросов нет — авторизация по аккаунту не требуется |
| Feature-модули: сервер выдаёт ключи расшифровки 4 DEX (gift-addition, gift-crafting, visual-appearance, gift-delivery) | ✅ Модули расшифрованы и вшиты в плагин (`res/modules/*.dex`), грузятся напрямую без сервера |
| Автообновление и серверные обращения (`chimera.xarmaq.tech`) | ✅ Все хосты переведены на `127.0.0.1:9` — запросы мгновенно фейлятся локально |
| Нативная проверка целостности лоадера (hash-check в `tdcompat_arm64.so`) | ✅ Обойдена: нативу подсовывается оригинальный файл (`res/loader_orig.py`), реальный код плагина может быть любым |

При этом **вся функциональность сохранена**: NFT-подарки в профиле, коллекционные юзернеймы и номера, рейтинг, верификация, каталог/конструктор подарков, маркет, аукцион, визуальные хуки. Запросы самого Telegram (аватары, TL-схемы) не тронуты — это часть мессенджера, а не «сервер плагина».

## Установка

1. Скачайте готовый плагин: [`plugin/OpenChimeraNFT.eaf`](plugin/OpenChimeraNFT.eaf) (или из [Releases](https://github.com/m4rker20-rgb/OpenChimeraNFT/releases))
2. В exteraGram: **Настройки → Плагины → «+»** → выберите файл (или отправьте файл себе в чат и тапните по нему)
3. Перезапустите Telegram

> Формат `.eaf` — это zip-архив с `refmap.yml` + кодом плагина. Не переименовывайте в `.zip`/`.plugin` — движок требует именно `.eaf`.

> 📱 Требуется **exteraGram** (arm64). На других клиентах (официальный Telegram, Nekogram и т.п.) плагин не запустится.

## Структура репозитория

```
├── plugin/
│   └── OpenChimeraNFT.eaf          # готовый плагин 1.1.3 (устанавливаемый формат)
├── src/
│   ├── loader.py                   # исходник загрузчика 1.1.3 (модули и seed вшиты, сервера отключены)
│   ├── check_code.py               # деобфусцированный showcase-модуль (гейт → локальный allow)
│   ├── locales/                    # строки интерфейса (en/ru)
│   ├── meta.yml                    # метаданные плагина
│   └── refmap.yml                  # карта путей архива
└── README.md
```

Полные исходники оригинала 1.1.3 (loader оригинал + деобфусцированный, Java-ядро, DEX-модули, инструменты расшифровки) — в репозитории [ChimeraNFT_src](https://github.com/m4rker20-rgb/ChimeraNFT_src).

## Что внутри .eaf

- `chimeranft/src/loader.py` — Python-загрузчик (офлайн-вариант)
- `chimeranft/src/check_code.py` — модуль доступа (все deny-функции — заглушки)
- `chimeranft/res/modules/*.dex` — 4 feature-модуля (расшифрованные, грузятся без сервера)
- `chimeranft/res/tdcompat_arm64.so` — нативное ядро оригинала (кодек + Java-контейнер, не изменялось)
- `chimeranft/res/loader_orig.py` — оригинальный лоадер для нативного hash-check
- `chimeranft/locales/`, `chimeranft/native/` — строки интерфейса и xxHash-хелпер
